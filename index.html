使用说明
  • 编辑权限：默认是只读浏览模式，可查看地图、悬停查看数值、拖动缩放、播放点亮、调整显示与样式（箭头颜色/线型、中心图标、气泡大小等）、重置为初始数据；点击右上角「登录」（账号 admin）后才可修改数值、用户、中心、箭头数据、备注文字与导入数据，退出后恢复只读。
  • 编辑数值：登录后点击地图上任意城市输入数值；该城市所在省份整体渐变着色（从省一端连续渐变到另一端），省份数值合计越大，颜色越不透明。
  • 用户标注：选中城市后在卡片中输入用户 ID 并点「添加」，用户将以「圆形气泡 + 指向箭头」的图钉展示在该城市上，同一城市多个用户自动纵向排列，可单独移除。
  • 搜索定位：顶部搜索框输入城市名（支持 / 快捷聚焦），确认后地图自动缩放定位并选中该城市；搜索框内可切换「城市 / 用户」模式，用户模式下按用户 ID 搜索。
  • 中心城市：在城市卡片中点击「设为中心城市」，支持设置多个；地图上将以特殊图标标出，样式与大小可在左下角调整。
  • 指向箭头：连线以城市为单位（每个发出箭头的城市各自连到中心城市）；可设置多个中心城市，添加时选择对应中心，一键批量时就近指向；线条粗细、实虚样式、颜色均可在左下角调整。
  • 配色说明：热力图采用固定渐变配色（#666BCE → #18B7F6 → #D7EEF6），不可自定义城市颜色。
  • 线段编号与点亮：线段编号默认隐藏，可用左下角「线段编号」开关显示；点击右上角「点亮」，先隐藏所有连线和数据效果，再按编号顺序依次点亮连线所在省份（渐显动画）、连线从起点城市匀速生长到中心；点亮速度可在左下角调整。
  • 地图标注：左下角可开关城市数值与城市名称显示。
  • 地图操作：滚轮缩放、按住拖动平移，右下角可重置视图。
  • 数据保存：所有数值与设置自动保存在浏览器本地，刷新页面不丢失；也可通过右上角「导出 / 导入」备份为 JSON 文件或从文件恢复。
